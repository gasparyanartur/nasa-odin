# Docs for the combined app

This folder is a copy of the root app's `docs/`. Two files here describe the combined app. The others describe the root app's features, which the combined app carries over, or are dated records of the root app's history. For the combined app itself, start with [the folder README](../README.md) and [the Marswalk modules](../src/marswalk/README.md).

| File | What it is |
|---|---|
| [backlog.md](backlog.md) | Current for the combined app: each feature's status here, with the file that implements it. |
| [boxwork-data.md](boxwork-data.md) | Current for the combined app: Boxwork data, coordinates and limits. |
| [datasets.md](datasets.md), [environment-data.md](environment-data.md), [field-data.md](field-data.md), [gale-data.md](gale-data.md), [science-data.md](science-data.md) | Copied from the root app. They describe features the combined app carries over. |
| [release.md](release.md), [submission.md](submission.md) | Copied from the root app. They describe the root app's release steps and its submission draft. |
| [plans/](plans/) | Dated records inherited from the root app. Each plan states what was true on its date. |
| [research/](research/) | Dated records inherited from the root app. |
| [evidence/](evidence/) | Dated screenshots, logs and checks from the root app's releases. None of them was made in the combined app. |

Two plans carry a note at the top because they name the old static Marswalk app, which is now only in git history at commit 66ee212: [the integration plan](plans/2026-11-14-hypersimulation-integration.md) and [the demo deployment plan](plans/2026-11-15-demo-deployment.md).
