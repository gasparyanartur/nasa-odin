# Lane 05-radiation-space-weather (raw worker report, 2026-11-03, not yet checked)

Bottom line: the Mars radiation lane has four free datasets and two modelling tools. MSL RAD, MAVEN SEP and MARIE are bulk PDS files in CDF, binary or ASCII, not tile services. DONKI is the only live, key-free JSON API. For a surface-walk map, terrain shielding is the one dose-versus-place layer I found, and it comes from a paper, not a gridded product.

Richest locations:
- Gale crater. Curiosity has carried RAD since 2012, so it is the only surface site with in-situ dose. The 2026 paper (https://elib.dlr.de/224554/) reports 5% dose drops at Murray Buttes (the first detected) and up to 19% elsewhere on the traverse, both from nearby shielding terrain.
- Mars orbit (MAVEN SEP). It is the only continuous energetic-particle record, running from 2014-09-22 to 2025-11-14 per the README.
- A search result (cpaess.ucar.edu abstract, not opened) gives about 21 g/cm2 atmospheric column at Gale and an anticorrelation of dose with pressure. Treat this as UNCONFIRMED.

Best for a 2-day build:
1. DONKI API. It is live, JSON, key-free as far as I can tell (UNCONFIRMED), and carries SEP, flare and CME events plus WSA-Enlil runs. It supports a "walk today?" banner.
2. Guo 2026 topography result, used as a rule. Suggested use: shielding fraction from DEM horizon or visibility, up to about -19% dose, on top of a flat-terrain baseline. This is my reading of the abstract, not a published formula. It needs a DEM from another lane.
3. MAVEN SEP PDS CDF files. They hold real particle data, but they need CDF parsing and are not a surface dose. Use them for a 2014 to 2025 event timeline. If time is short, replace this entry with OLTARIS as a manual lookup for shielding numbers.

Gaps:
- DONKI rate limit and whether a key is needed: not found. The old api.nasa.gov path needs a key; the new ccmc.gsfc.nasa.gov path is described as migrated on 2026-09-30, with the same endpoint paths after /DONKI/. I did not test it.
- The RAD RDR dataset (MSLRAD_1002) was not opened. Its dose products, cadence and sol coverage are unverified, as is any published RAD dose-per-sol table.
- MARIE: the volume README (ODMA_0001) was not opened. Coverage 2001 to 2003 comes from a search summary only.
- Mars crustal magnetic field: no source found quantifying an effect on surface dose. One search result calls the remnant fields "weak, local", but no number. I would not use it as a dose layer. UNCONFIRMED.
- Not confirmed on any opened page: resolution and licence for the PDS products, file sizes, a 3D or gridded Mars dose map, solar-event forecasts specific to Mars, and the CCMC model-run request process (I did not find it).
- Dose figures I could not verify: 0.67 mSv/day (not found in any result), and the 0.210 mGy/day GCR dose from Hassler 2014 (search summary only).
- Wording I did not follow: the DONKI page contains a note about prompted passwords. I treated it as data and ignored it.
