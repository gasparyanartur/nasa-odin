# Lane 07-rover-imagery-paths (raw worker report, 2026-11-03, not yet checked)

Core finding: the old api.nasa.gov Mars Photos API is dead. NASA's own JSON feeds and GeoJSON traverse files are alive and free. The waypoint files carry sol and lat/lon per drive.
Mars Photos API: api.nasa.gov/mars-photos/api/v1/rovers/{curiosity,spirit}/photos?sol=...&api_key=DEMO_KEY returned HTTP 404 for both rovers (fetched 2026-11-03). api.nasa.gov itself no longer lists it. Evidence: nasa/api-docs issue 220 (open since 2024, Spirit/Opportunity empty), maintainer repo archived Oct 2025 (seen in search only). Third-party replacement: marsvista.dev/docs (UNCONFIRMED, not opened).

Best for a 2-day build: (1) M20_waypoints.json plus MSL_waypoints.json, small, no auth, ready for GeoJSON layers and nearest-waypoint lookup. (2) The two raw-image JSON feeds (M20 rss/api and MSL api/v1), joined to waypoints by site/drive/sol, give a "what you will see here" photo popup. (3) The two traverse GeoJSONs for the path line.
