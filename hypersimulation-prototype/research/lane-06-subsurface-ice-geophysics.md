Richest locations:
- Arcadia, Acidalia, Onilus, Utopia (N mid-latitudes): named SWIM study regions, where 4 SWIM data sets overlap (PSI 2019 release). Arcadia was the pilot swath.
- Deuteronilus Mensae, 37-47N, 25-35W: the only mid-latitude SHARAD 3D volume (sharad.psi.edu/3D.php).
- Planum Boreum and Planum Australe: dense SHARAD stacks (3,399 and 2,093 passes) and 3D volumes. This is polar ice, too cold for a walk.
- InSight site (northern lowlands): the only direct seismic crust constraint; all other crustal thickness is gravity-modelled (Zenodo record).
- Perseverance traverse: RIMFAX sols 1740-1859 in Release 16. The crater name is not on the pages I opened, so it is UNCONFIRMED.
- Rule from JPL: 0-60N, with the most useful ice near the southern edge of the northern mid-latitude band.

Best for a 2-day build:
1. SWIM 2.0 GeoTIFFs (swim.psi.edu/SWIM2Products.php): a ready, normalized -1 to +1 raster in three depth bands. Drops straight into a map layer, and it is the direct answer to where there is shallow ice.
2. Wieczorek crustal thickness grids (Zenodo 6477509): a global 0.25 deg ASCII grid, easy to parse, but 2.7 GB for the full archive. Pull only the grid files you need.
3. USGS SIM 3292 geologic map (PDF, public domain): the one clean geology layer. The GIS version is not confirmed, so budget time to georeference the PDF, or search for the GIS package. SHARAD 3D is too heavy (tens to hundreds of GB), and ODE REST is a good fallback to query SHARAD footprints.
