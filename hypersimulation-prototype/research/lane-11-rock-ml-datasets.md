# Lane 11-rock-ml-datasets (raw worker report, 2026-11-03, not yet checked)

Core finding: no free global Mars boulder or rock-hazard raster was found. Boulder and rock data is local (per HiRISE image or per landing site). The usable free stack is AI4Mars (rover-view terrain labels), DoMars16k (CTX landform classes, with weights), and Prieur BoulderNet (boulder outlines plus weights). Licence is "UNCONF" wherever the opened page showed none; I did not guess.

Richest locations:
- InSight (Homestead hollow): the only site with rock-level outlines, diameters and DEM (Caltech record, opened). Near-field rock abundance from 0.6% to ~3-5% (search snippet only).
- Jezero, Oxia Planum, Lycus Sulci: DoMars16k's mapping script is preconfigured for these three CTX scenes (GitHub README, opened).
- Four HiRISE scenes carry the Mars-Bench boulder labels: ESP_017355_2260, ESP_025650_2165, ESP_028537_2270, ESP_037018_2170 (Zenodo file list, opened).
- Rover sites (Gale, Jezero, Meridiani, Gusev): AI4Mars rock/sand labels along the traverses.
- Rockfall zones: Bickel GRL 2024 reports 1,383 locations, 82N to 53S, mostly crater and fossae walls (search snippet only).

Best for a 2-day build:
1. AI4Mars (Zenodo 15995036): a ready 4-class terrain label set and the only NASA-owned one. Use it to train or demo a rock/sand/bedrock segmenter. It is 16 GB, so subset it.
2. DoMars16k with its pretrained models: weights are included, so you can run `make_map.py` on a CTX strip and get a landform map with no training. The cliff, ridge and rough-terrain classes work as obstacle proxies at ~1.2 km patch scale.
3. Prieur BoulderNet weights plus the Mars-Bench boulder tiles: boulder-level HiRISE masks with weights and CC-BY-4.0 on the Mars-Bench part. The weights were trained on Mars, Moon and Earth together, and the labelled set is small (~87 rows).

Gaps:
- Licences for most Zenodo and USGS records did not appear in the scraped text. Check each record's rights field before reuse.
- No global rock-abundance raster at HiRISE or TES resolution found. Only the 60 km Viking map is confirmed. The Golombek Mars 2020 / Jezero rock-abundance data was not found, and the Pathfinder/MER tables were not opened.
- Bickel rockfall catalogue: download location unconfirmed (the DOI link 404'd on Nature Index). Robbins licence and count not confirmed on a primary page. RMaM-2020 (Edmond), HiRISENet (Zenodo 2538136), S5Mars, Mars32k, MarsScapes and Kaggle AI4Mars: seen in search results only, not opened.
- SPOC weights: none found. Mars-Bench model licences unread.
- AI4Mars label counts conflict between NASA (~326K on 35K images) and Zenodo v0.6 (~425K on ~50K).
