# Archive

Older versions, kept for reference and for attribution. Not needed to run the current app in `../hypersimulation-prototype/`.

- `martian-map-v1/`: the earlier Martian Map app, moved here unchanged from the repository root on 2026-11-15. To run it: `cd archive/martian-map-v1 && npm install && npm run dev`. Its scripts and documents still name its old paths (for example `hypersimulation-prototype/app/`, which is now `archive/marswalk-static-data/`), so its data-preparation scripts need those paths adjusted before use.
- `marswalk-static-data/`: source data of the first static Marswalk prototype with `DATA-LICENSE.md`, `LICENSE` and `sources.json`, moved here unchanged from `hypersimulation-prototype/app/`.
