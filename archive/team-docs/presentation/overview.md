* What does it do?   (AI friendly)
  * Initial Draft Perhaps? Our project is a three-part navigation system for Mars, made up of a base station with an interactive 3D globe, a handheld tablet (PDA) and an astronaut HUD. It maps thermal, radiation, topography and water-ice layers, tracks rovers, probes and astronauts, and plans the safest route between points, including waypoints for tasks like taking photos or setting up sensor arrays. NASA satellite data is combined with data uploaded by astronauts, rovers and probes to build an ever-expanding environment map. The station holds the global view, the tablet handles planning and layer-toggling, and the HUD shows local conditions, a minimap, compass and life-support warnings, so astronauts can stay focused on their surroundings rather than a screen. Devices send periodic location pulses (probes every 5 minutes, rovers every 15, astronauts every 30), allowing a search area to be estimated if one is lost. Because the system is scalable and modular, with new data overwriting old to create waypoints and points of interest, it adapts as missions grow. We hope to achieve easy, safe traversal and route planning that accounts for geology, radiation and the wider environment. We used AI-assisted coding to build the system and integrate NASA satellite data, taking interface inspiration from Subnautica, No Man’s Sky, Google Maps and Google Earth.
